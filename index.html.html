IMPLEMENTATION — TWO STACK ARCHITECTURE

class Stack<T> {
  private List<T> data = new ArrayList<>();
  void push(T item) { data.add(item); }            // O(1)
  T pop() { return data.remove(data.size()-1); }   // O(1)
  T peek() { return data.get(data.size()-1); }     // O(1)
  boolean isEmpty() { return data.isEmpty(); }     // O(1)
  int size() { return data.size(); }               // O(1)
}

class BrowserHistory {
  Stack<String> backStack = new Stack<>();
  Stack<String> forwardStack = new Stack<>();
  String current;

  void visit(String page) {
    backStack.push(current);
    forwardStack.clear();      // new path invalidates forward history
    current = page;
  }

  String back() {
    if (backStack.isEmpty()) return current;   // edge case
    forwardStack.push(current);
    current = backStack.pop();
    return current;
  }

  String forward() {
    if (forwardStack.isEmpty()) return current; // edge case
    backStack.push(current);
    current = forwardStack.pop();
    return current;
  }
}

STACK LAB — LIFO

A Stack is a Last-In-First-Out (LIFO) structure. The last element pushed is always the first one popped. Core operations: push, pop, peek, isEmpty, size — each O(1).
